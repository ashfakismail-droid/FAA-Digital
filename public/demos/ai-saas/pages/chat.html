Show me the API code for fetching this data programmatically.
AI
Here's a JavaScript example using the NovaAI SDK:
api/usage.js 
// Initialize NovaAI client
const nova = new NovaAIClient({ apiKey: 'your-api-key' });

// Fetch usage analytics
const usage = await nova.usage.getCredits({
  startDate: '2024-07-01',
  endDate: '2024-07-31'
});

console.log(usage.creditsUsed); // 8452
